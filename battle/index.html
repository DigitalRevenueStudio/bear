Scope & privacy

This prototype supports editable numeric comparison. It does not identify hero portraits, skill icons, equipment badges, permanent-loss rules or optimal ratios. OCR row matching is experimental and cannot reliably interpret arbitrary report layouts.

Use original, unedited report text where possible; crop out irrelevant sections for better recognition. Names and coordinates are not required. Nothing is saved automatically. Exports contain reviewed fields and user confirmations—not images or raw OCR. Refreshing clears the session unless you export it.

Engine: Tesseract.js 5, loaded only when you request OCR. External code and model downloads require internet access. On-device processing can be slow on phones. If OCR fails, manual entry works without it.
